# 3. Install the Package

Install the Fixed Deposit SDK using npm:

    npm install @finspringinnovations/fixed-deposit

Or using Yarn:

    yarn add @finspringinnovations/fixed-deposit

The package bundles its own iOS frameworks and Android .aar file. No additional package download is required.
