# 6. Launching the SDK

## Customer Information

The customer profile is required for the registration step.

The following customer information is passed to `FixedDeposit.launch()`:

- `customerId`: the current customer id
- `correlationId`: a correlation id
- `firstName`: customer first name
- `lastName`: customer last name
- `gender`: customer gender
- `email`: customer email address
- `dob`: customer date of birth
- `mobileNumber`: customer mobile number

The `apiBaseUrl` and `partnerCode` values are issued by Finspring for each environment.
